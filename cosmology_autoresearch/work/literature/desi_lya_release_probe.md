# DESI DR2 Lyα Results IV release probe

**Checked:** 2026-09-24. Metadata/source audit only; no files downloaded in this probe, no fitting, and no covariance inferred from figures. Only this report was written.

## Finding

I did not find an official, machine-readable Results IV Lyα replacement likelihood or its joint covariance with the non-Lyα DR2 BAO measurements. The paper reports enough rounded summary statistics in Eq. (26) to form an explicit *approximate two-dimensional Gaussian compression* for the Lyα distances, but this is not a released likelihood file and does not specify covariance with the other DR2 BAO coordinates.

For a simple BAO screen, use either the released Results I/II 13-coordinate vector unchanged, or label a Results IV replacement as a screening approximation: remove its last two Lyα entries and insert the Eq. (26) Lyα pair. Do not add Results IV as a second independent Lyα measurement. For an exact joint Results IV reproduction, wait for the official file/covariance or obtain it from the collaboration through ordinary public channels.

## Results IV paper and overlap

- **Paper/version:** [DESI DR2 Results IV, arXiv:2607.27410 v3](https://arxiv.org/abs/2607.27410), revised 2026-08-04; full local PDF and extracted text read (`context/papers/desi_lya_ap.pdf`, 2,160,430 bytes; SHA-256 `6fcc44addcd8843a46fc6016753955a5f16c7a3b2593c5c8e74250dc1c632674`). Exact HTML version: [v3](https://arxiv.org/html/2607.27410v3).
- **Paper's own release statement:** Sec. VIII, PDF p. 30 / [HTML lines 688–690](https://arxiv.org/html/2607.27410v3), says analysis data “will be made public” with DR2 and figure data “will be available in a Zenodo repository”; it supplies no record DOI or direct likelihood URL. This is a forward-looking statement, not evidence that those files are currently available.
- **Printed usable summary:** Sec. V.3, Eqs. (24)–(26), PDF pp. 18–20: Eq. (26) gives the combined full-shape AP+BAO distance pair at $z_{\rm eff}=2.33$, $D_M/r_d=39.32\pm0.33$, $D_H/r_d=8.600\pm0.066$, with correlation $\rho=0.225$. Those printed values determine a rounded 2×2 Gaussian covariance, e.g. $C_{ij}=\rho_{ij}\sigma_i\sigma_j$; no plot digitization is involved. The separate AP ratio summaries in Eqs. (24)–(25) are not an additional independent distance likelihood.
- **Why it overlaps:** Sec. II / [HTML line 163](https://arxiv.org/html/2607.27410v3) says Results IV uses the same DR2 observations as the Lyα BAO analysis; its effective redshift is 2.33. In Sec. VI.1, [HTML lines 498–502](https://arxiv.org/html/2607.27410v3), the authors describe DESI BAO from galaxy/quasar clustering and “DESI BAO+Lyα FS” when adding the new full-shape result; they include the earlier Lyα BAO result “when necessary” for comparisons. Their reported cosmological combination is not itself a released likelihood/covariance artifact.

The currently local Results II Gaussian files are pinned to [`CobayaSampler/bao_data` commit `bb0c1c9009dc76d1391300e169e8df38fd1096db`](https://github.com/CobayaSampler/bao_data/tree/bb0c1c9009dc76d1391300e169e8df38fd1096db/desi_bao_dr2): `desi_gaussian_bao_ALL_GCcomb_mean.txt` (local `context/data/desi_dr2_mean.txt`, 472 bytes, SHA-256 `9ac154ab583ce759c0f7eef3c978c7c70a6ead2d18774caceadf1a350a640585`) and `desi_gaussian_bao_ALL_GCcomb_cov.txt` (local `context/data/desi_dr2_cov.txt`, 2,547 bytes, SHA-256 `252a143274c8a07c78694c119617d36594f6d7965d00319ca611c6ffb886e509`). Its row order puts row 12 at (z=2.33, D_H/r_s=8.6315457), and row 13 at (z=2.33, D_M/r_s=38.9889740). The old covariance has zero cross-block entries between these two rows and the first eleven, but that is the Results I/II covariance, not a published Results IV cross-covariance. A block replacement using it is therefore an explicit approximation, not the exact updated DR2 joint likelihood.

## Official release-channel audit

1. [DESI DR2 publication index](https://data.desi.lbl.gov/doc/papers/dr2/) currently lists Results I, Results II, Results IV and supporting validation/mocks papers. Its only direct cosmology-data link is Results II's “Cosmology chains and posterior maximization results”; no Results IV likelihood/covariance link is listed.
2. The [official DESI papers page](https://data.desi.lbl.gov/doc/papers/) says the underlying DR2 spectra and redshifts have not yet been released, while BAO cosmology chains and posterior-maximization files are available. The official [`public/papers/y3/` directory listing](https://data.desi.lbl.gov/public/papers/y3/) checked on 2026-09-24 contains only 2025-era items: `Andrade.Validation.BAO.pdf` (4,807,595 B), `Brodzeller.DLA.Lya.pdf` (1,729,813 B), `Casas.validationBAOLya.pdf` (2,706,231 B), `Elbers.Neutrinos.pdf` (1,804,735 B), `KP.DR1.pdf` (16,178,603 B), `KP.DR2.BAO.Lya.pdf` (1,712,588 B), `KP.DR2.BAO.pdf` (11,717,801 B), `Lodha.DE.pdf` (2,957,448 B), plus `bao-cosmo-params/` and `README.md` (110 B). No Results IV data/covariance file is in that listing. These PDF files are not candidate AP likelihood products.
3. The linked [official BAO cosmology-chain README](https://data.desi.lbl.gov/public/papers/y3/bao-cosmo-params/README.html) identifies its content as Results II MCMC chains and posterior maximizations and points to the public Results II BAO likelihoods. Its `desi-bao-all` definition combines Results I Lyα BAO with Results II galaxy/quasar BAO; it is the existing vector, not an updated Results IV product. The README does not provide an AP/full-shape likelihood.
4. The [official DESI Zenodo community](https://zenodo.org/communities/desi-pub) API query for `2607.27410` returned zero records on 2026-09-24: [reproducible query](https://zenodo.org/api/records?communities=desi-pub&q=2607.27410&size=10). A query for the validation companion `2607.27411` also returned zero. The paper's promised figure-data Zenodo record was not located.

### Newly dated adjacent record (not a replacement)

An adjacent newer DESI community item located is [Zenodo record 22135162](https://zenodo.org/records/22135162), DOI [10.5281/zenodo.22135162](https://doi.org/10.5281/zenodo.22135162), published 2026-08-28: “Supplemental data for: A Unified Tracer Analysis of DESI DR2 Baryon Acoustic Oscillations.” Metadata lists `dr2-unified-tracer-data.zip`, 39,574,324 bytes, CC BY 4.0, MD5 `a41b53928487770625eea0e073ca29f5`. Metadata only was inspected; no archive download or SHA-256 was made. Its title and associated paper [arXiv:2608.27830](https://arxiv.org/abs/2608.27830) identify unified galaxy/quasar BAO figure/supplemental data, not the Results IV Lyα full-shape replacement or its covariance. It must not be substituted for that missing artifact.

## Referenced analysis repository

Results IV points to [Vega](https://github.com/andreicuceu/vega), the Lyα correlation-model/inference software. The repository is accessible, but the paper does not pin a commit. On the check date the GitHub API reported `master` head `01f1a9784767e43e68c89ee4464c2bdcb15420c0`, dated 2026-09-15 (commit URL: https://github.com/andreicuceu/vega/commit/01f1a9784767e43e68c89ee4464c2bdcb15420c0); repository license is GPL-3.0. Its tree has generic example configurations including `examples/DESI_data_setup/lyaxlya-baseline_combined.ini` (1,738 B), `lyaxlyb-baseline_combined.ini` (1,738 B), `lyaxqso-baseline_combined.ini` (1,642 B), and `lybxqso-baseline_combined.ini` (1,642 B), but no Results IV-specific measurement/covariance or ready-to-use likelihood artifact was identified at that commit. A generic unit-test file such as `tests/data/qsoauto_cov_20x20.txt` is not a DR2 release product. Repository source code is available; correspondence of current `master` to the exact paper analysis configuration is unpinned/unverified.
