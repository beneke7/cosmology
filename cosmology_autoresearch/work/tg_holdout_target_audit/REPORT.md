# Whole-galaxy holdout target audit — 2024 thermodynamic gravity

**Decision (pre-fit):** nominate **NGC 4559** as the primary held-out galaxy and **NGC 7793** as fallback. The ranking uses only catalogue quality/geometry, distance information, available source products, radial coverage, and a coarse baryonic-mass contrast. No TG fit, curve score, residual inspection, or parameter tuning was performed. SPARC `Vobs` values were not used in the ranking; the local Rotmod check was limited to file headers, point counts, and radii.

For NGC 4559, use McQuinn et al.'s independent TRGB result `D=8.91±0.19(stat)±0.29(sys) Mpc`, not SPARC's Hubble-flow `9.00±2.70 Mpc`, when fixing physical radii and rescaling photometric/H I masses. The SPARC row identifies the HI/Hα curve reference as Barbieri et al. (2005); HALOGAS is a later, separate source-map release. The data are distinct products, but no raw-observation or cross-covariance audit was done.

At the common SPARC benchmark `Υ*=0.5` and using its `Mgas=1.33 MHI` convention, the catalogue proxy is
`Mb = 0.5 L[3.6] + 1.33 MHI`.
This gives `Mb(3198)≈3.36×10^10 M☉`; for NGC 4559 it gives `1.74×10^10 M☉` at 9.0 Mpc, or `1.71×10^10 M☉` rescaled to 8.91 Mpc. Thus `Mb(4559)/Mb(3198)≈0.51`: a meaningful but moderate factor-two contrast, corresponding to a `~1.40` K ratio under the proposed exponent. NGC 7793's same coarse proxy is `4.67×10^9 M☉`, a ratio `~0.14` (K ratio `~2.68`), explaining its fallback status despite less favorable geometry. These are screening masses from catalog luminosity and HI mass—not a fit, not a final P5+resolved-HI source mass, and not a precision error budget. The source analysis must independently convert the acquired old-star map and selected H I map, with a stated M/L, helium convention, and distance.

## Scaling and preregistration contract

For the stationary 2024 equation `∇²φ − K|∇φ|² = 4πGρ`, dimensional consistency gives `[K]=[velocity]⁻²`. The field equation alone does **not** imply a mass law. To obtain the brief's `K∝Mb⁻¹/²`, add both assumptions: comparable dimensionless TG response for homologous source/branch/boundary families, so `K Vflat²` is common; and a common baryonic Tully–Fisher normalization `Vflat⁴=A Mb` in a genuinely flat-curve regime. Then `K ∝ Vflat⁻² = (A Mb)⁻¹/²`. This scaling is conditional on flat outer curves, a consistent baryonic census and distance convention, common `A`, homologous profiles/geometry, and a fixed physical exterior prescription. None of these follows from the PDE; the exponent, `A`/normalization, training sample, and uncertainty must be fixed before opening NGC 4559's velocities. One NGC 3198 calibrator can set a normalization under a declared procedure, but cannot establish the exponent or independently validate the relation.

**Holdout status:** NGC 4559 is a whole-*galaxy* outcome holdout conditional on that frozen law if its curve is sealed before source construction and prediction. This audit chose it using target metadata and mass contrast only; it did not use curve values or residuals. It is not strict statistical independence: the target's catalog baryonic proxy is part of the prediction and selection, HI mass and HI kinematics can share distance/flux/geometry systematics, and no joint covariance is supplied. Quality/coverage screening is also a selection condition. The test cannot independently establish the exponent from one train galaxy; it tests a conditional prediction at one new mass.

Before any prediction: (1) freeze the target, mass recipe, slope `−1/2`, training normalization and uncertainty, and all source priors; (2) derive the stellar and HI source from P5 plus resolved H I without spherical inversion of target `Vobs`; (3) declare stellar M/L and vertical profiles, HI inclination/PA and thin/thick layer options, helium/opacity, molecular/ionized gas treatment, and an outer stellar-tail bracket; (4) use an isolated/exterior-matched physical boundary, never observed endpoint velocities; (5) fix SPARC distance/inclination treatment and evaluate the complete held-out curve once under the matching likelihood. The supplied 2024 article's NGC 3198 method instead pseudo-sphericalizes disk components and uses observed endpoint derivatives as boundary data (Eqs. 41–42, p. 8); that is not a predictive holdout contract. See the exact-paper reading card and existing alternatives contract linked below.

## Remaining uncertainties / artifacts

- NGC 4559 S4G P5 map is acquired and hashed, but no pixel-level mass profile was derived. Its official analysis ellipse covers about 12 kpc, versus a 20.8 kpc RC endpoint; outer stellar mass needs a predeclared extrapolation or bracket.
- NGC 4559's HALOGAS DR1 v2 H I column map was subsequently downloaded from the official Zenodo record. Its 4,245,120-byte size and release MD5 `e2c57a3f8a4cca5f76ffeffde0bedbb9` match; local SHA-256 is `320d2de1e29adbfdc7bd9023d58ed6dec78bf7d8b1ba326ffdc064150e252bba`. The FITS header's `BUNIT` says `JY/BEAM.km/s`, while `HISTORY` records the moment-0 to column-density conversion and exact beam factors; this stale-unit risk must be resolved from the released processing record before mass conversion. Header beam is 28.379×13.104″ at 4″ pixels. Version 2 changes only NGC 4448 products; NGC 4559 products are unchanged from v1. The HALOGAS record license is CC BY 4.0.
- No NGC 4559 THINGS map was required/checked; HALOGAS suffices for a resolved-gas source. NGC 7793 fallback THINGS moment-0 availability was HEAD-checked but no map was downloaded.
- Stellar M/L, map-to-mass calibration, PA/warp and radial inclination behavior, 3-D stellar/HI vertical profiles, HI opacity, H₂/ionized gas, outer stellar continuation, and distance/geometry covariance remain unpropagated. SPARC has pointwise errors but no full radial covariance.
- The 2024 target method's endpoint-derived boundary must be replaced; the physical exterior matching/finite-domain convergence contract remains to be implemented before a valid holdout prediction.
